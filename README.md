# Análisis de Rendimiento de Campañas de Marketing Digital

## Descripción del Proyecto
Análisis de 10.000 campañas de marketing digital utilizando Python. El objetivo fue identificar las combinaciones de **plataforma** y **objetivo de campaña** más rentables, y generar recomendaciones de optimización de presupuesto basadas en KPIs reales.

## Principales Hallazgos
- **TikTok** y **Facebook** son las plataformas con mayor ROAS.
- La mejor combinación es **TikTok + Lead Generation** (ROAS 13.61).
- La industria de **Finance** presenta el mayor retorno (ROAS 12.72).
- **LinkedIn** y las campañas de **Brand Awareness** tienen el menor rendimiento.

## KPIs Analizados
- ROAS (Return on Ad Spend)
- CTR (Click-Through Rate)
- CPC (Cost Per Click)
- Conversion Rate
- CPA (Cost Per Acquisition)

## Herramientas Utilizadas
